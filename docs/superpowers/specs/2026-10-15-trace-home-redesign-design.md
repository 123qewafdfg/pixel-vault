# 隐像·溯源 v1 首页重排设计

## 目标

在不改变提取、网盘登录、更新、协议和缓存功能的前提下，缩小首页控件占用并重新建立视觉层级。本次只调整 `trace` 提取版首页，完整版首页保持原样。

## 布局

- 标题固定为“一张图下，皆是秘密”，整句使用相同字体样式。
- 标题、“开始提取”和“网盘登录”组成的主操作组在可用屏幕中水平、垂直居中。
- “提取”是唯一高强调主操作，直接复用完整版 `HomeAction`，确保尺寸、圆角、字号和箭头样式完全一致。
- “网盘登录”紧随主操作下方，使用更紧凑的描边次按钮。
- 移除提取版的“应用”分区标题和大面积中部功能容器。
- “检测更新”“用户协议与隐私政策”“清理缓存”放到页面底部紧凑工具栏。
- 保留右上角明暗模式切换与现有背景装饰，但收紧顶部和操作区留白。

## 视觉原则

- 绿色只承担主要动作，低频功能使用表面色与弱强调文字。
- 保留现有深色/浅色主题自适应，不引入新的 UI 依赖。
- 主内容限制最大宽度，避免在大屏上盲目拉伸。
- 交互控件保持可点击高度，底部工具栏允许文字省略以适配窄屏。

## 验证

- 构建并测试 `traceRelease`，执行 R8、资源收缩、Lint 与单元测试。
- 核对标题、包名、版本、签名、模型资源和 APK 体积。
- 若有可用 Android 设备，安装后截图核对真实布局；没有设备时明确说明未做真机视觉验证。
