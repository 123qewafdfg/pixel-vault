# 隐像·溯源 v1 设计

## 定位

“隐像·溯源”是“隐像”的独立提取版本。它只负责从含盲水印的图片或五位口令码中定位、下载、校验并恢复隐藏文件，不提供任何嵌入或上传能力。

## 应用身份

- 应用名：隐像·溯源
- 包名：`com.trustmark.extractlite`
- 版本：`versionCode 1`、`versionName 1.0`
- 构建产物：签名 Release APK，不交付 Debug 包
- 与完整版关系：同一源码仓库、独立构建变体，可与完整版同时安装

## 保留功能

- 导入一张或多张含盲水印的图片
- 输入五位口令码直接提取
- 查询既有隐像资源记录
- 匿名下载普通直链或 B站承载图片
- 网盘登录、授权和网盘原图下载
- 分片 SHA-256 校验、解密、文件恢复
- 恢复结果预览与保存
- 缓存清理、用户协议与隐私政策
- 提取版独立更新通道

## 移除功能

- 隐藏文件导入和智能压缩
- 承载图选择、生成、保存与登记
- B站登录、上传、投稿和长期直链选项
- 上传后匿名校验设置
- 所有嵌入流程入口和相关教程

删除 B站登录不影响匿名下载既有 B站承载图片。

## 下载并发

- 使用 Kotlin 结构化并发：`coroutineScope + async + awaitAll`
- 使用信号量限制活跃分片下载数
- Wi-Fi 最多 8 路，其他网络最多 4 路
- 每个分片最多重试 3 次，每次下载后校验 SHA-256
- 任一分片最终失败时取消同组任务并清理未完成文件
- 聚合所有活跃分片的已下载字节、总字节和速度，保证界面进度不倒退
- 多张入口图片逐张解码，避免多个原生模型任务同时造成内存峰值；单个资源内部的分片并发下载

## 界面与图标

- 提取版首页只提供开始提取、网盘登录、更新、协议和缓存操作
- 提取页延续完整版的布局和动效
- 图标保留完整版的白底网格和几何主体，只做轻微青绿色差异，不添加下载箭头或文字

## 更新隔离

提取版的版本查询携带独立 `extract` 通道。完整版和提取版不得互相接收 APK 或增量补丁。v1 首次发布只需要完整 APK；后续版本可从提取版 v1 生成增量补丁。

## 验收

- Release APK 的包名、名称和版本正确
- 可与完整版同时安装
- 首页没有嵌入和 B站登录入口
- 网盘登录可用
- 普通直链、B站承载图和网盘资源均可提取
- 多分片下载存在受控并发，进度单调且文件校验通过
- 完整版 v15 的构建配置与行为不回退
