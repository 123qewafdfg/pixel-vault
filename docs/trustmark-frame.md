# TrustMark 资源 ID 帧

## 固定配置

- 模型变体：TrustMark Variant Q
- 数据层：BCH_SUPER
- 有效载荷：40 bit
- 纠错能力：最多 8 个 bit flip

## 载荷布局

```text
bit  0..31  资源 ID，32-bit 无符号整数，大端位序
bit 32..39  固定填充，必须全部为 0
```

分享图片只承载 4 字节资源 ID。填充位不属于业务数据。

## 生成和验证

1. 服务端使用密码学安全随机源生成 32-bit 无符号 ID。
2. ID 为数据库主键；碰撞时重新生成。
3. 编码前将 ID 转换为 32 个二进制位，并追加 8 个 `0`。
4. 提取后先验证后 8 bit 全为 `0`；任一位非零即拒绝。
5. 前端和 API 使用固定 8 位大写十六进制文本表示，例如 `7F3A91C2`。
6. 该 ID 是访问索引，不是高强度访问密钥。

## 互通要求

浏览器实现必须通过以下测试后才能接入 UI：

- Web 嵌入 → 官方 TrustMark Rust/Python 解码。
- 官方 TrustMark Rust/Python 嵌入 → Web 解码。
- Web 嵌入 → Web 解码。
- 填充位非零时拒绝。
- ID 的逐位结果与固定测试向量一致。
