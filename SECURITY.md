# 安全策略 / Security Policy

## 中文

当前项目是未经完整安全审计的实验性软件。请勿在公开 Issue、Discussion、截图或日志中提交密钥、后端地址、个人数据或可直接利用的漏洞细节。

报告漏洞时，请优先使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告功能，并包含：

- 受影响版本和组件
- 可复现的最小步骤
- 实际影响
- 建议修复方向（如有）

在修复发布前，请不要公开披露漏洞细节。凭据一旦泄露，应立即撤销或轮换；仅从 Git 历史删除并不能使凭据失效。

## English

This is experimental software without a comprehensive security audit. Never place credentials, private backend locations, personal data, or directly exploitable details in public issues, discussions, screenshots, or logs.

Please use GitHub's **Security → Report a vulnerability** private reporting flow. Include the affected version/component, minimal reproduction steps, impact, and a proposed mitigation when available. Do not publicly disclose details before a fix is released. Revoke or rotate exposed credentials immediately.
